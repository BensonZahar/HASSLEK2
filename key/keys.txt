#
#  Формат: JSON. Человек -> его устройства -> ID. Названия устройств и имена
#  любые, загрузчик смотрит только на ID (16 символов: цифры 0-9 и буквы a-f).
#
#  Как выдать доступ:
#    1. Человек запускает клиент и видит на экране загрузки:
#       «Нет доступа. Ваш ID: xxxxxxxxxxxxxxxx»
#    2. Он присылает этот ID.
#    3. Добавляете его в блок выше. Новый человек:
#         "Вася": {
#           "телефон": "0123456789abcdef"
#         }
#       Новое устройство у того же человека (эмулятор, второй телефон) -
#       ещё одна строка внутри его блока (после предыдущей строки нужна запятая):
#         "Вася": {
#           "телефон": "0123456789abcdef",
#           "memu": "fedcba9876543210"
#         }
#       Между людьми тоже запятая: } , "Вася": { ... }
#    4. Сохраняете и делаете push. Через 3-5 минут после перезапуска игры заработает.
#
#  Клоны: если они подписаны тем же ключом, что и обычный APK (cloner сам берёт
#  konstt_key.pem / near_key.pem), у обычной версии и всех клонов на устройстве
#  ОДИН ID - вписывать нужно одну строку на устройство.
#
#  Как забрать доступ:
#    Удалите строку (или весь блок человека) и сделайте push. Чтобы отключить
#    временно, поставьте # в начало строки - загрузчик её пропустит.
#
#  Если после правки доступа нет - проверьте запятые и кавычки, и что ID ровно
#  16 символов. Файл не должен содержать других 16-значных hex-слов вне # строк.
