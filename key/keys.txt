#
#  Как выдать доступ:
#    1. Друг запускает клиент и видит на экране загрузки:
#       «Нет доступа. Ваш ID: xxxxxxxxxxxxxxxx»
#    2. Он присылает вам этот ID (16 символов: цифры 0-9 и буквы a-f).
#    3. Вы добавляете строку в блок КЛЮЧИ выше: ID, затем # и имя.
#    4. Сохраняете и делаете push. Через 3-5 минут у него заработает
#       (после перезапуска игры).
#
#  Как забрать доступ:
#    Поставьте # в начало строки (или удалите её) и сделайте push.
#    При следующем запуске игры у человека моды не загрузятся.
#
#  Правила:
#    - один ID на строку
#    - всё, что после #, — комментарий, его можно писать как угодно
#    - регистр букв не важен, пустые строки и пробелы не мешают
#
#  Пример строк (в блоке КЛЮЧИ без # в начале):
#    0123456789abcdef   # Вася
#    fedcba9876543210   # Петя
