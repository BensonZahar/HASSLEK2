# Hassle Mods — моды без пересборки APK

Структура: `Mods/` — ядро и моды (.c), `loader/hassle_loader.c` — загрузчик (вшивается в APK один раз), `build_konstt.py` — сборка, `.github/workflows/build.yml` — CI.

**Ядро и моды.** `Mods/hassle_core.c` — единственный обязательный файл (IL2CPP, журнал, ожидание готовности игры, реестр чат-команд). Остальное — независимые моды, каждый подключает только ядро: `hassle_near.c` (игроки рядом, HTTP :17771, `/nearlog`), `hassle_rec.c` (`/rec`), `hassle_nocol.c` (`/nocol`), `hassle_route.c` (`/route`). Любой можно добавить или удалить, остальные продолжат работать. `python3 build_konstt.py --check` собирает каждый мод отдельно с одним ядром и ловит случайные зависимости между модами.

**Новый мод:** скопируйте `Mods/_template.c` в `Mods/hassle_имя.c` → `git push` в main → Actions соберёт бандл и опубликует его в ветку `dist` → игра докачает при следующем запуске.

**APK пересобирать нужно только** при смене самого загрузчика (`loader/hassle_loader.c`) или адреса репозитория: возьмите артефакт `konstt-so` (`libkonstt_loader_*.so`) и пропустите через `run.bat` как раньше.

**Первый раз:** репозиторий должен быть публичным (игра качает с raw.githubusercontent.com без токена). Включите 2FA на GitHub — скачанный код выполняется внутри игры.

**Выключатель:** файл `konstt_off` (как раньше). **Журналы:** `loader.log` и `konstt.log` в папке HLOG. Защита от вылетов: если бандл 3 запуска подряд не дожил до 25 секунд, он отключается на час или до новой сборки.
