# Hassle Mods — моды без пересборки APK

Структура: `Mods/` — все моды (.c), `loader/hassle_loader.c` — загрузчик (вшивается в APK один раз), `build_near.py` — сборка, `.github/workflows/build.yml` — CI.

**Новый мод:** скопируйте `Mods/_template.c` в `Mods/hassle_имя.c` → `git push` в main → Actions соберёт бандл и опубликует его в ветку `dist` → игра докачает при следующем запуске.

**APK пересобирать нужно только** при смене самого загрузчика (`loader/hassle_loader.c`) или адреса репозитория: возьмите артефакт `near-so` (`libHassleExtended_*.so`) и пропустите через `run.bat` как раньше.

**Первый раз:** репозиторий должен быть публичным (игра качает с raw.githubusercontent.com без токена). Включите 2FA на GitHub — скачанный код выполняется внутри игры.

**Выключатель:** файл `near_off` (как раньше). **Журналы:** `loader.log` и `near.log` в папке HLOG. Защита от вылетов: если бандл 3 запуска подряд не дожил до 25 секунд, он отключается на час или до новой сборки.
